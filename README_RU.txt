РУССКИЕ КРОССВОРДЫ — Android-проект

В игре: русский язык, 3 уровня, проверка ответов, подсказки, очки и сохранение прогресса на устройстве. Игра рассчитана на работу без интернета после установки.

СБОРКА APK БЕЗ КОМПЬЮТЕРА (через GitHub Actions):
1. Создайте на GitHub новый репозиторий с именем RusskieKrossvordy. Можно выбрать Public или Private.
2. Загрузите в репозиторий ВСЕ файлы и папки из этой папки проекта, сохранив структуру каталогов. Важно: файл .github/workflows/android.yml должен оказаться именно по пути .github/workflows/android.yml в корне репозитория.
3. После добавления файлов в ветку main откройте вкладку Actions и выберите workflow "Build Android APK". Если workflow не запустился автоматически, откройте его и нажмите Run workflow.
4. Дождитесь зелёной галочки у запуска сборки.
5. Откройте завершённый запуск и скачайте артефакт russkie-krossvordy-apk. Это ZIP-архив, внутри которого будет app-debug.apk.
6. Распакуйте архив на телефоне, нажмите app-debug.apk и при необходимости разрешите установку приложений из этого источника в настройках Android.

Примечание: APK создаётся облачной сборкой GitHub Actions. Он не был заранее собран или протестирован на физическом устройстве. Не публикуйте в репозитории пароли или личные данные.
