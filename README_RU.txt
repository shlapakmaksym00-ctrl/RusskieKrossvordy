РУССКИЕ КРОССВОРДЫ — Android-проект

В проекте есть автономная игра на русском языке: 3 уровня, проверка ответов, подсказки, очки и сохранение прогресса на устройстве.

КАК СОБРАТЬ APK:
1. Установите Android Studio на компьютер.
2. Распакуйте архив.
3. В Android Studio выберите Open и укажите папку RusskieKrossvordy.
4. Дождитесь синхронизации Gradle и установки Android SDK 35.
5. Откройте Build → Build Bundle(s) / APK(s) → Build APK(s).
6. APK появится в app/build/outputs/apk/debug/app-debug.apk.

Для сборки нужен интернет на этапе загрузки Gradle/Android SDK. После установки сама игра работает без интернета.

Примечание: в этой среде я подготовил исходный Android-проект, но не собрал и не проверил APK на физическом устройстве.
